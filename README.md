Tourist Hotel Inventory Management SystemA desktop inventory management application developed for Tourist Hotel (Arba Minch) to streamline stock tracking, manage hotel inventory categories, and provide administrative oversight on stock levels and movements.🛠️ Tech Stack & FrameworksLanguage: C#UI Framework: Windows Forms (WinForms)ORM: Entity Framework Core (EF Core)Database: Microsoft SQL ServerArchitecture: Component-based / Layered Architecture✨ Key Features🔐 User Authentication & Role ManagementSecure login interface for staff and administrators with role-based access control.📦 Stock & Inventory TrackingReal-time automated stock calculation and item level updates.Item categorization tailored for hotel inventory (kitchen items, beverages, room supplies, maintenance assets).🔄 Inbound & Outbound OperationsLog received items, internal stock transfers, and usage records.📊 Dashboard & ReportingVisual overview of stock levels with low-stock alerts and audit logs.🗄️ Database SetupThe project uses Entity Framework Core with SQL Server. Follow these steps to prepare your local database:Ensure Microsoft SQL Server and SQL Server Management Studio (SSMS) are installed.Open the solution in Visual Studio.Update the connection string in App.config (or DbContext configuration) to match your local SQL Server instance:XML<connectionStrings>
  <add name="DefaultConnection" 
       connectionString="Server=YOUR_SERVER_NAME;Database=TouristHotelInventoryDB;Trusted_Connection=True;TrustServerCertificate=True;" 
       providerName="System.Data.SqlClient" />
</connectionStrings>
Open Package Manager Console in Visual Studio (Tools > NuGet Package Manager > Package Manager Console) and run migrations:PowerShellUpdate-Database
